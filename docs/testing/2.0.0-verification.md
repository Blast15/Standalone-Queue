Ngày 11/10/2026. JDK Temurin 21.0.12.1+1, Maven 3.9.9, coding container dùng chung. Baseline `b64d22d6149baabf5928dc823e524aceb0e60e7b` là main đã gộp giai đoạn 3.

## Build và correctness

- Baseline: `mvn -B clean verify` thành công, 131 unit/regression + 14 Paper API integration = 145 test.
- 2.0.0: `mvn -B clean install` (gồm verify) thành công, **144 unit/regression + 14 integration = 158 test**, không failure/error/skip.
- Staging probe 2.0.0: `mvn -B clean verify -f staging-probe/pom.xml` thành công.
- Recovery có 12 ca: roundtrip/ownership, replacement failure giữ snapshot tốt, file tạm crash bị bỏ qua, corrupt/truncate/oversize/schema mới, restart FIFO/heartbeat/không IP/không in-flight, TTL đúng deadline/future clock, quyền/capacity mới, final flush/ownership release, corrupt fallback, NAT rebind/quota, provider failure và shutdown giữa recovery, restart-only settings.
- PhaseThreeRegressionTest có thêm ca expiry counters và completed queued-wait histogram; JOIN lặp không tăng sample.
- `QueueRecoveryTest` + `PhaseThreeRegressionTest` chạy thêm 5 vòng liên tiếp: 35 test/vòng, tổng 175 lượt, không failure/error/skip; không dùng sleep để đồng bộ recovery.
- `git diff --check` và parse workflow YAML thành công.

Các integration test dựng event object Paper API và player/provider doubles; không chạy Paper server/EventBus/network thực. Test file tạm mô phỏng crash trước replace, không khẳng định đã thử power-loss hoặc kill process giữa filesystem syscall.

## Load smoke comparison

Harness giữ nguyên: 500 người chờ, 50 worker, priority giả, permission future hoàn thành ngay, capacity 1 đã đầy; các lượt đo phải IN_QUEUE, không tăng in-flight/capacity. 3 JVM fork mỗi variant/anti-bot, đổi thứ tự chạy. Anti-bot-off 10000 measured attempts/fork; on 2000/fork; tổng 72000 measured attempts cho cả baseline/candidate. Persistence tắt trong harness; chi phí flush đồng thời đang bật persistence cần đo trên staging. [Workload chi tiết](phase-3-benchmark.md).

## Tái chạy

```bash
mvn -B clean install
mvn -B clean verify -f staging-probe/pom.xml
git worktree add --detach ../queue-baseline b64d22d6149baabf5928dc823e524aceb0e60e7b
mvn -B -f ../queue-baseline/pom.xml -DskipTests test-compile
python3 scripts/compare-queue-load.py --baseline-classes ../queue-baseline/target/classes --candidate-label 2.0.0 --forks 3
```

Maven là build nguồn chuẩn của CI. Bổ sung: 144 unit + 14 Paper API integration đạt trên cả Java 21 và Java 25 với API 1.21.11.
