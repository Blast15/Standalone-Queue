# Security Policy

StandaloneQueue controls admission to a Paper server. It is not a DDoS scrubber and cannot stop traffic before the Minecraft process receives it.

Please avoid public issue reports for exploitable problems. Contact the repository maintainer privately with a description, affected version, reproduction steps, and logs with player IPs removed.

Keep anti-joinbot protection enabled on crack servers and combine it with host firewall rules, connection limits, and a network-layer DDoS provider for large attacks.
